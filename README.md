# Doruk Media — Multilingual Digital & Social Media Agency Website

A responsive, multilingual (`TR`, `EN`, `RU`, `AR` with RTL support) web platform for **Doruk Media** (Cyprus Digital & Social Media Agency).

## Features

- **4-Language Localization**: Dedicated localized routes for Turkish (`/tr/`), English (`/en/`), Russian (`/ru/`), and Arabic (`/ar/`).
- **Dark / Light Theme Engine**: Persistent theme switching with `localStorage`.
- **Interactive UI Components**: Particle canvas background, filterable portfolio showcase, client testimonial carousel, service detail modal, and FAQ accordion.
- **SEO Ready**: Includes `sitemap.xml`, `robots.txt`, canonical links, and responsive viewport meta configuration.

## Project Structure

```text
Doruk-media/
├── index.html          # Root language redirect entry
├── tr/index.html       # Turkish localization
├── en/index.html       # English localization
├── ru/index.html       # Russian localization
├── ar/index.html       # Arabic localization (RTL)
├── css/style.css       # Responsive stylesheet & theme variables
├── js/script.js        # Interactive UI logic, keyboard accessibility & theme persistence
├── robots.txt          # Search engine crawler rules
└── sitemap.xml         # Multilingual XML sitemap
```
